# Hi, I'm ZiTong Wang 👋

> **I build systems to understand how things work, and games to explore how things could be.**

I'm a Software Engineering undergraduate at Southeast University. My GitHub is a record of what I've learned, what I've built, and occasionally, what I've imagined.

Some projects start with a technical question: *How does a coroutine scheduler work? How can distributed nodes stay consistent?*

Others start with a different question: *What if this card game worked differently? What would make it more fun to play with friends?*

I enjoy both sides of building software — understanding the principles beneath the surface and turning unusual ideas into things people can actually use and play.

---

## 🎮 Games & Creative Projects

### [ProGyakuten](https://github.com/WTJunzhu/ProGyakuten) — My Flagship Project

My most ambitious personal game project. A place where game rules, strategic decisions, multiplayer interaction, and software engineering come together.

I enjoy not only playing games, but also understanding their mechanics, rethinking their rules, and building my own versions of the experience.

### [RivalCourts-NAISHImultiplayer](https://github.com/WTJunzhu/RivalCourts-NAISHImultiplayer) — Reimagining a Classic

A multiplayer, localized adaptation of the classic NAISHI card game — bringing a traditional game experience into a new setting.

### [VR-waste-sorting](https://github.com/WTJunzhu/VR-waste-sorting) — My First VR Experiment

My first attempt at building a VR game with Unity, exploring immersive interaction and a new way for players to engage with a virtual environment.

### More Game Experiments

I also explore AI-assisted implementations of classic tabletop games, including **Skull King** and **Texas Hold'em** — learning by recreating familiar mechanics and experimenting with ideas.
